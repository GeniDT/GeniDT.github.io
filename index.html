About

I work on data platforms end to end, from ingestion to reporting. I build layered lakehouse transformations with PySpark and Spark SQL, design semantic models for Power BI, and tune dashboards so they stay fast as data grows.

I also care about the less visible work: data quality checks, documentation, and pipelines the next person can maintain easily.

My years as a clinical dietitian taught me how data is created at the source and how to work closely with the people who rely on it. It's also why I have a particular interest in health data.

Projects

  • E-Commerce Lakehouse on AWS

    Serverless lakehouse that ingests e-commerce transaction files, validates and transforms them with Spark on AWS Glue, and stores them as Delta Lake tables for querying in Athena. Step Functions orchestrates the workflow end to end.

    Glue (Spark), Delta Lake, Step Functions, Lambda, Athena, GitHub Actions

    View the code on GitHub

  • Real-Time Trip Analytics Pipeline

    Event-driven pipeline for a ride-hailing scenario. Kinesis streams trip events, Lambda validates and deduplicates them into DynamoDB, and a scheduled EventBridge job writes daily KPIs to S3, with SNS alerts and CI/CD.

    Kinesis, Lambda, DynamoDB, EventBridge, S3, GitHub Actions

    View the code on GitHub

  • Car Rental Data Pipeline on Amazon EMR

    Batch pipeline that processes car rental data with PySpark on EMR to produce vehicle, location and customer KPIs, catalogued in Glue and queried with Athena. Step Functions orchestrates the full run.

    PySpark, EMR, Glue Data Catalog, Athena, Step Functions

    View the code on GitHub

  • Music Streaming KPI Pipeline with Airflow

    Daily pipeline orchestrated by Apache Airflow. Glue crawlers and Spark jobs validate raw stream data in S3, compute KPIs such as top songs and genres, and load them into DynamoDB for dashboards.

    Apache Airflow, Glue (Spark), S3, DynamoDB

    View the code on GitHub

  • Sales Performance Dashboard

    Power BI dashboard comparing year-to-date with prior-year sales, product performance and gross profit by country. Data cleaned in Power Query, with DAX measures for the KPIs.

    Power BI, DAX, Power Query

  • Healthcare Data Cleaning in Python Health data
